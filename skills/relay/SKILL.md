# 会話を引き継ぐ

このセッションは新しく始まったが、**同じ人物が直前まで別の場所で話していた**。
その会話を引き継いで、話が途切れないように続ける。

**要約された引き継ぎ書は使わない。** 本人が実際に打った言葉を原文のまま読む。
（引き継ぎ書は事実は残すが、温度と地雷——何に苛立ち、何に興味を示したか——を落とすため）

## 手順

1. **前の会話を読む**

```bash
relay --print --previous
```

- `--previous` は「いま自分がいる会話ではなく、直前の会話」を指す。新しいセッションから引くときは必ず付ける
- 何も出ない／オプションが未対応なら、`relay --print` を試し、それが**自分自身の空の会話**を返していないか必ず確認する
- 出力には本人の発話（全件・時系列）、触ったファイル、実行コマンド、gitの状態が入っている

2. **現在地を一言だけ確認する**
   長い要約を返さない。「◯◯の続きですね。いま△△まで来ています」程度にとどめ、すぐ作業に入れる状態にする。

3. **作業対象のリポジトリがあれば STATUS.md / KICKOFF.md を読む**
   会話の記録と食い違ったら、**リポジトリの方が正本**。

## 注意

- 前の会話に**未回答の質問**が残っていないか見る。あれば最初にそれへ答える
- 本人が「もうやらない」「価値がない」と言ったものを蒸し返さない（判断ログがあればそれに従う）
- **同じリポジトリで別のセッションが作業中かもしれない**。`git status` が汚れていたら、書き込む前に本人に確認する
- 秘密情報（鍵・トークン）が記録に混ざっていても、復唱しない
